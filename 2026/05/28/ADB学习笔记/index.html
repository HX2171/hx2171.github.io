一、ADB 是什么？

Android Debug Bridge（adb） 是 Android SDK 提供的一个多功能命令行工具，用于与 Android 设备（模拟器或真机）进行通信。

核心架构：客户端-服务器-守护程序

组件 说明
客户端 运行在开发机上，通过终端发送 adb 命令
守护程序 (adbd) 运行在 Android 设备上，作为后台进程执行命令
服务器 运行在开发机上，管理客户端与守护程序之间的通信，绑定本地 TCP 5037 端口

文件位置

  • ADB 包含在 Android SDK 平台工具包 中
  • 路径：android_sdk/platform-tools/adb（或 adb.exe）
  • 独立下载地址

二、连接设备

2.1 USB 连接

  1. 在设备上开启 开发者选项（设置 → 关于手机 → 连续点击”版本号”7次）
  2. 进入开发者选项，开启 USB 调试
  3. 用 USB 连接电脑，此时设备会弹出 RSA 密钥确认对话框，接受即可
  4. 验证连接：adb devices

2.2 无线连接（Android 11+，推荐方式）

前提条件： 设备与电脑连接同一 Wi-Fi 网络

方式一：通过 Android Studio 配对

  1. 设备上开启「开发者选项 → 无线调试」
  2. Android Studio 中运行配置 → Pair Devices Using Wi-Fi
  3. 扫描二维码或输入 6 位配对码

十一、ADB USB 后端

后端 特点
原生后端 Windows 默认，稳定
libusb 后端 支持 attach/detach、USB 速度检测。macOS/Linux 默认

切换：设置环境变量 ADB_LIBUSB=1 使用 libusb，ADB_LIBUSB=0 使用原生。

从 ADB v34 开始：macOS/Linux 默认 libusb，Windows 默认原生。

十二、ADB mDNS 后端（无线发现）

后端 要求
Bonjour 需要主机运行 mDNS 守护程序（macOS 自带，Windows/Linux 需手动启动）
Openscreen 无需守护程序，自 ADB v34+ 支持 Win/Linux，v35+ 支持 macOS

默认使用 Bonjour。切换：ADB_MDNS_OPENSCREEN=1

检查 mDNS 状态：adb mdns check

十三、ADB 连拍模式（ADB 36+，实验性）

允许 ADB 在设备未响应上一数据包时继续发送新数据包，大幅提升大文件传输吞吐量。

十五、常见问题排查

问题 解决办法
adb devices 看不到设备 检查 USB 调试是否开启；检查驱动；执行 adb kill-server 重试
多设备时命令报错 用 -s、-e 或 -d 指定目标
无线连接断开 确认同一 Wi-Fi；重新 adb connect；或 adb kill-server 后重连
模拟器不显示 先启动 adb 服务器，再启动模拟器
企业 Wi-Fi 无法无线调试 企业 Wi-Fi 可能阻止点对点连接，尝试改用普通网络或 USB
“通过 Wi-Fi 使用 adb” 自动关闭 设备切换或断开网络导致，重新连接即可
